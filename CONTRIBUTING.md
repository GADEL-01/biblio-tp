# Contribuer à Biblio

## Signaler un problème ou proposer une évolution

Ouvrir une issue avec le bon modèle (bug, évolution ou question).

## Processus

1. Créer une branche depuis `main` : `type/n°-mots-cles`
   - `fix/3-double-emprunt`
   - `docs/12-readme`
   - `feat/5-afficher-emprunteur`
2. Commiter avec un message clair : `fix: ...` / `docs: ...` / `feat: ...`
3. Ouvrir une PR avec `Closes #n` dans la description
4. Attendre la review d'un camarade avant de merger

## Règles

- Pas de push direct sur `main`
- Une branche = une issue
- Toute PR doit être relue avant le merge
